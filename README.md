# Python Calculator 

A simple command-line calculator built with python.

## Description

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Division by zero protection
6. Invalid number handling
7. Invalid operation handling

## Technologies

- Python 3

## Python concepts Used

- Variables
- User input and output
- Data type conversion (float)
- conditional statements (if / elif / else)
- Nested conditions
- Arithetic operators
- Compation operators
- Exception handling (try / except)
- built-in exceptions (valueerror)

## How to Run

1. install python 3
2. Download or clone this repository
3. Open the project folder in your terminal
4. Run following command: python main.py

## About

This project was created as part of my python learning journey to practice arithmetic operations, conditional statements, and exception handling.
